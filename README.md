# Bryan Campos

Completing the Computer Science program and developing this ePortfolio has allowed me to transform from a student writing functional code into a developer who designs scalable, maintainable, and secure systems. Throughout the program, I developed not only technical skills but also a professional mindset grounded in structured problem solving, collaboration, and continuous improvement. The capstone experience required me to revisit earlier work, critically evaluate it, and enhance it across multiple dimensions, which reinforced my growth in software design, algorithms, databases, and security.

One of the most significant areas of growth has been in software engineering and architectural thinking. In earlier coursework, my programs were primarily focused on functionality. Through courses such as CS-410 and CS-499, I learned to refactor code into modular structures, remove global state, apply separation of concerns, and implement repository based data access layers. These improvements demonstrate my ability to design and evaluate computing solutions using established computer science practices while managing design trade offs. Rather than simply making code work, I now focus on clarity, maintainability, and extensibility.

My understanding of algorithms and data structures also matured significantly. In enhancing my artifact, I implemented dictionary based storage for efficient O(1) lookups, sorting mechanisms with O(n log n) complexity, filtering and searching operations, and aggregation functions. These enhancements required deliberate selection of data structures and reinforced the importance of performance awareness and scalability. This directly supports my ability to apply algorithmic principles to real world application design.

Database integration represented another major step forward. By implementing a CSV backed repository with full CRUD functionality, schema validation, and safe write operations, I demonstrated understanding of persistence, data integrity, and controlled data access. I learned how introducing persistent storage changes application architecture and requires careful separation between business logic and storage mechanisms. This experience strengthened my ability to implement computing solutions that deliver value through structured data management.

Security awareness has also become a core part of my development approach. Through this capstone, I incorporated input validation, integrity checks, confirmation prompts for destructive actions, and role based access control. These design decisions reflect a growing security mindset that anticipates misuse and mitigates vulnerabilities at the architectural level rather than treating security as an afterthought.

Collaboration and communication have been reinforced throughout the program. Writing structured narratives, presenting a code review, and organizing this ePortfolio required translating technical decisions into clear explanations suitable for diverse audiences. This aligns with industry expectations where developers must justify design decisions to stakeholders, managers, and team members.

The artifacts included in this ePortfolio collectively demonstrate my growth in, software design and modular architecture, data structure selection and algorithmic reasoning, persistent data management and database concepts, secure system design and validation practices, and professional technical communication. Together, these enhancements show not only what I can build, but how I think as a computer science professional. This portfolio represents my readiness to contribute to professional software development environments where scalable architecture, performance awareness, and secure data handling are essential.
